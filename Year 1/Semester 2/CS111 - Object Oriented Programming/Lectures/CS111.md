## 📌 Course Overview
Object-Oriented Programming (OOP) principles and software design using Java. Focuses on robust class and object design, the four fundamental pillars of OOP (Encapsulation, Abstraction, Inheritance, Polymorphism), interfaces, abstract classes, robust exception handling, generic programming, the Java Collections Framework, and introductory object modeling using UML diagrams.

## 📑 Core Topics
1. **Core OOP Concepts:** Classes, instances, constructors, instance methods, static members, access modifiers (`private`, `public`, `protected`, package-private).
2. **Encapsulation & Information Hiding:** Getters/Setters, data invariants, and object immutability.
3. **Inheritance & Polymorphism:** `extends`, `super`, method overriding vs. overloading, dynamic method dispatch (runtime polymorphism).
4. **Abstract Classes & Interfaces:** `implements`, interface-based design, contract-driven architecture, default and static interface methods.
5. **Exception Handling:** `try-catch-finally` blocks, `throw`, `throws`, checked vs. unchecked exceptions, custom domain exceptions.
6. **Object Modeling & UML:** Class diagrams, sequence diagrams, relationship modeling (association, aggregation, composition), Mermaid syntax.
