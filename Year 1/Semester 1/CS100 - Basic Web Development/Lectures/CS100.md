> [!info] Navigation: [[CSTU40]] > [[Year 1]] > [[Year 1 Semester 1]] > [[CS100]]

## 📌 Course Overview
Foundational course in web application development. Covers the fundamentals of web architecture, HTTP/HTTPS protocols, semantic page structuring using HTML5, responsive styling with modern CSS3 (Flexbox, Grid), dynamic client-side scripting with JavaScript (DOM manipulation, event handling), and version control workflows with Git for collaborative software development.

## 📑 Core Topics
1. **Introduction to Web & Internet Protocols:** Client-Server model, DNS resolution, HTTP/HTTPS request-response lifecycle.
2. **HTML5 Semantic Structure:** Elements, forms, input validation, media elements, accessibility (a11y).
3. **CSS3 & Responsive Design:** Box model, Flexbox layout, CSS Grid, media queries, mobile-first design philosophy.
4. **JavaScript Fundamentals & DOM Manipulation:** Data types, functions, event listeners, Fetch API, and asynchronous JavaScript (AJAX).
5. **Version Control & Team Collaboration:** Git branching strategies, merge conflicts, pull requests, and GitHub collaborative workflows.
