# 💻 CS102 — Basic Programming

> [!info] Navigation: [[CSTU40]] > [[Year 1]] > [[Year 1 Semester 1]] > [[CS102]]

---

## 📌 Course Overview
Introductory computer programming using the C programming language. Emphasizes algorithmic problem-solving skills, structured programming principles, low-level memory management, control flow structures, modular functions, arrays, pointers, user-defined data structures (`struct`), and file I/O operations.

## 📑 Core Topics
1. **Introduction to C & Development Environments:** GCC/Clang compilers, Standard I/O (`printf`, `scanf`), primitive data types, operators.
2. **Control Structures:** Conditional statements (`if-else`, `switch-case`), iteration and loop constructs (`for`, `while`, `do-while`).
3. **Functions & Scope:** Modular programming, pass-by-value vs. pass-by-reference (simulated via pointers), recursion.
4. **Arrays & Strings:** 1D and 2D arrays, string manipulation (`string.h`), buffer bounds management.
5. **Pointers & Memory Architecture:** Memory addresses, dereferencing, pointer arithmetic, dynamic memory allocation (`malloc`, `calloc`, `realloc`, `free`).
6. **Structures & File I/O:** `struct`, `typedef`, binary and text file handling (`fopen`, `fread`, `fwrite`, `fclose`), multi-file compilation, and automated build scripts (Makefiles).
