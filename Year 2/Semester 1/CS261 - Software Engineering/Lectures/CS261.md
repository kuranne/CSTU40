# 🛠️ CS261 — Software Engineering

> [!info] Navigation: [[CSTU40]] > [[Year 2]] > [[Year 2 Semester 1]] > [[CS261]]

---

## 👨‍🏫 Instructor Information & Course Overview
- **Instructor:** Dr. Songsakdi Rongviriyapanish
- **Course Description:** Systematic study of engineering methodologies for large-scale software system development. Covers the complete software lifecycle, process models (Waterfall, Agile, Scrum), requirements engineering, architectural design, software quality assurance (QA) & verification testing, and software development economics & maintenance.

## 📑 Upcoming Roadmap & Topics
1. **Software Process Models:** Waterfall, Prototyping, Spiral, Agile Manifesto, Scrum sprints & Kanban boards.
2. **Requirements Engineering:** Functional vs. Non-functional requirements, User Stories, Use Case modeling.
3. **Software Architecture & Design Patterns:** Layered architecture, MVC, Microservices, Gang of Four (GoF) design patterns.
4. **Software Verification & Validation:** Unit testing, integration testing, Test-Driven Development (TDD), static code analysis, CI/CD pipelines.
5. **Software Project Management:** Effort estimation (COCOMO, Function Points), risk management, Git branching strategies.
