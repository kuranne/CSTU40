# Lesson

## Classify by type of User

1. Normal Person (Easiest / Cheapest)
2. Business Domain (Normal / Good Price)
	1. Retail
	2. Banking
	3. Financial
	4. Healt care
	5. Manufacturing
3. Goverment (Hardest / Expensive)

## Classify by Software

1. **System Software** (Operating system, NAS, Cloud Server, Firewall, Driver, Container, Visualizer, Compiler, Interpreter) -> Base Program must to install in any devices for setup the application
	1. **Utility Software** (Antivirus)
2. **Application Software** (IDE, any relate other cli/tui/gui software)
	1. Verticle Software (Only for one domain)
	2. Horizon Software (Can provide many domain)
3. **Platform** (SaaS, Mobile Application, Window-based App, Web Service, Cloud-base)
