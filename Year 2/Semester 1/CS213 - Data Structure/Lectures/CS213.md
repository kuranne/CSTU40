## 📑 Course Curriculum Roadmap
1. **Foundations:** OOP principles, advanced C++ features, process memory layout, asymptotic complexity analysis ($O, \Omega, \Theta$).
2. **Linear Structures:** Dynamic arrays, singly/doubly linked lists, stacks, queues, and deques.
3. **Trees & Hierarchical Structures:** Binary trees, Binary Search Trees (BST), balanced search trees (AVL, Red-Black), heaps, and priority queues.
4. **Sets & Dictionaries:** Hash tables, hash functions, collision resolution strategies (chaining, open addressing).
5. **Graph Data Structures:** Graph representations (adjacency matrix, adjacency list), Depth-First Search (DFS), Breadth-First Search (BFS), Minimum Spanning Trees (Prim, Kruskal), Shortest Path algorithms (Dijkstra).
6. **Algorithm Design & Analysis:** Sorting algorithms (Quicksort, Mergesort, Heapsort), Divide and Conquer, Greedy algorithms, and Dynamic Programming.
