จุดประสงค์
------------------------------------------------------------
ให้นักศึกษาเข้าใจว่า "ชื่ออาร์เรย์คือที่อยู่ของสมาชิกตัวแรก"
และเดินอาร์เรย์ด้วยพอยเตอร์ได้ โดยใช้
  - dereference (*p)      : อ่าน/เขียนค่าที่พอยเตอร์ชี้อยู่
  - pointer arithmetic    : p++ เลื่อนไป "สมาชิกตัวถัดไป"
                            (ไม่ใช่ไบต์ถัดไป)
  - a + n                 : ตำแหน่งถัดจากสมาชิกตัวสุดท้าย
  - สายอักขระแบบอาร์เรย์ของ char ที่จบด้วย '\0'


** กติกาสำคัญของข้อนี้ **
------------------------------------------------------------
ในไฟล์ arrayptr.cpp "ห้ามใช้เครื่องหมาย [ ]" ทุกกรณี
ให้เดินอาร์เรย์ด้วยพอยเตอร์เท่านั้น เช่น  *p , p++ , *(p + i)
(อาจารย์จะเปิดไฟล์ตรวจด้วยตาอีกครั้ง หากพบ [ ] จะถูกหักคะแนน)


ไฟล์ในโฟลเดอร์นี้ (มีทั้งหมด 3 ไฟล์)
------------------------------------------------------------
  1) arrayptr.h    - การประกาศฟังก์ชัน      (ให้มาสมบูรณ์ ห้ามแก้)
  2) arrayptr.cpp  - โค้ดการทำงาน           (ต้องเติม 3 จุด)
  3) main.cpp      - โปรแกรมตรวจคะแนน       (สมบูรณ์แล้ว ห้ามแก้)


สิ่งที่ต้องทำ มีทั้งหมด 3 จุด (อยู่ในไฟล์ arrayptr.cpp ทั้งหมด)
------------------------------------------------------------
  [TODO #1]  int maxWithPointer(const int* a, int n)     10 คะแนน
       คืนค่ามากที่สุดในจำนวนเต็ม n ตัวที่เริ่มต้นที่ที่อยู่ a
       (สมมติได้ว่า n >= 1)
       ระวัง: ต้องเริ่มจาก *a ไม่ใช่เริ่มจาก 0
              มิฉะนั้นกรณีที่ทุกตัวติดลบจะได้คำตอบผิด

  [TODO #2]  int* findFirst(int* a, int n, int target)   10 คะแนน
       คืน "พอยเตอร์" ที่ชี้ไปยังสมาชิก "ตัวแรก" ที่มีค่าเท่ากับ
       target ถ้าไม่พบให้คืน NULL
       ระวัง: ต้องคืนตัวพอยเตอร์ p ไม่ใช่ *p
              และต้องเป็น "ตัวแรก" ที่เจอ (พบแล้ว return ทันที)

  [TODO #3]  int myStrLen(const char* s)                 10 คะแนน
       คืนความยาวของสายอักขระ s คือจำนวนตัวอักษรก่อนถึง '\0'
       ห้ามเรียกใช้ strlen()
       ระวัง: ต้องไม่นับตัว '\0' รวมเข้าไปด้วย


วิธีคอมไพล์และรัน (บน Windows)
