จุดประสงค์
------------------------------------------------------------
ให้นักศึกษาเข้าใจ
  - การใช้ struct รวบรวมข้อมูลที่เกี่ยวข้องกันไว้เป็นก้อนเดียว
    และการมีอาร์เรย์เป็นสมาชิกอยู่ภายใน struct
  - การเข้าถึงสมาชิกด้วย  .  (เมื่อเป็นตัวแปร object)
    และด้วย  ->  (เมื่อเป็นพอยเตอร์)  ซึ่ง s->total มีค่าเท่ากับ
    (*s).total
  - เหตุผลที่ต้องส่ง struct เข้าฟังก์ชันแบบพอยเตอร์ เมื่อ
    ต้องการให้ฟังก์ชัน "แก้ค่า" ของ struct ตัวจริงได้
    (ถ้าส่งแบบ pass by value จะได้แค่สำเนา แก้แล้วไม่มีผล)
  - การทำงานกับ "อาร์เรย์ของ struct"


ไฟล์ในโฟลเดอร์นี้ (มีทั้งหมด 3 ไฟล์)
------------------------------------------------------------
  1) student.h    - นิยาม struct + ประกาศฟังก์ชัน (ให้มาสมบูรณ์ ห้ามแก้)
  2) student.cpp  - โค้ดการทำงาน                 (ต้องเติม 4 จุด)
  3) main.cpp     - โปรแกรมตรวจคะแนน             (สมบูรณ์แล้ว ห้ามแก้)


หน้าตาของ struct (อยู่ใน student.h)
------------------------------------------------------------
  struct StudentRecord {
      char   name[NAME_LEN];      // ชื่อ (สายอักขระแบบอาร์เรย์ของ char)
      double hw[HW_COUNT];        // คะแนนการบ้าน 4 ชิ้น
      double exam[EXAM_COUNT];    // คะแนนสอบ 2 ครั้ง
      double total;               // คะแนนรวม
  };
